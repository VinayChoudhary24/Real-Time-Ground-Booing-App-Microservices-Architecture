<---- REDIS-BULLMQ SETUP ---->
1. Install Redis at Global level on machine. if windows First install wsl and install redis from it.
2. Setup redis config i.e redisClient, connection etc. Connect and run redis in server.ts file. 
3. Run the the Following cmd in Project Directory bash terminal
   -- npm i ioredis
   -- npm i bullmq
   -- npm i @bull-board/express
   -- npm i @bull-board/api
4. Configure the Cron Jobs with bullMQ i.e cron.queue, cron.scheduler, cron.worker
5. Register the routes for bullMQ UI Dashboard
// ------------------ Bull Board ------------------ //

serverAdapter.setBasePath('/admin/queues');

<---- Google Login SETUP ---->
1. Create a Application on console.cloud.google from header section
2. After Creation Select the created Application from Notifications section
3. Get the ClientID and Secret. Click on Navigation menu > APIs & Services > Credentials.
4. Now Click on Create Credentials > OAuth ClientID > Configure Consent Screen > Click Get Started.
5. Enter the App Details, Audience Etc. and Finish the project Configuration.
6. Click Create OAuth Client > Select Application Type. Add 'Authorized JavaScript origins' which will request Google 
i.e 'http://localhost:5173'. Now add 'Authorized redirect URIs' where users will be redirected and we will get 
the users data from Google 'http://localhost:5173/oauth2/callback' than Click on Create.
7. Copy the ClientID and Secret for Application.
8. Now Install Google-auth-library. npm i google-auth-library@0.11.0-0 or just npm i google-auth-library
